# Хувилбарын тэмдэглэл

Энэ баримт бичиг нь платформын `main` branch-ийг мөрддөг. Онцлох сүүлийн үеийн
өөрчлөлтүүд (хамгийн сүүлийнхээс эхлэн):

- **`sso.dgov.mn` руу rebrand** — SSO *хэрэглэгч* (consumer) гадаргууг устгаж,
  платформыг identity **provider** байхад төвлөрүүлсэн; branding нь
  "DAN-Government SSO / dan-dgov-mn"-ээс `sso.dgov.mn` руу шилжсэн.
- **Migration нэгтгэл** — өмнөх feature тус бүрийн migration-ууд (1–37) нь ганц
  `1_init_schema` хос болон шахагдаж, эх хувилбарууд нь `migrations/old/`-д
  архивлагдсан. Нэгтгэсэн init нь `search_path=public` тохируулдаг.
- UI-д **eID үйл ажиллагаа төрлөөр бүлэглэгдсэн**; **super admin-ууд зөвхөн өөрсдийн
  системийг хардаг**.
- **Super Admin систем** нь өөрийн дээд түвшний хэсэг болж дэвшсэн; landing-themes
  цэс түүн доор шилжсэн.
- **Super-admin туслах хүснэгт + MFA onboarding** — super admin-ууд тусгай
  `superadmin_accounts` хүснэгтэд хадгалагдаж, урилга → Google → eID → email OTP →
  TOTP wizard-аар дамжин onboarding хийгддэг.

!!! note
    Урагшаа харсан замын зураглал (нийлүүлсэн ба төлөвлөсөн)-ийн хувьд repository-ийн
    `ROADMAP.md`-г үзнэ үү. Энэ хуудас нь codebase-д харагдах нийлүүлэгдсэн
    өөрчлөлтүүдийг нэгтгэдэг; энэ нь git түүхийг орлохгүй.

## Хянан үзэх явцад тэмдэглэсэн баримт бичгийн зөрүү

Энэ сайтыг гаргасан кодын хяналт нь нийлүүлэгдсэн docs/spec нь кодоос хоцорсон хэд
хэдэн газрыг илрүүлсэн. Тэдгээрийг холбогдох газарт inline тэмдэглэсэн бөгөөд энд
нэгтгэв:

- Үүсгэсэн `swagger.json` нь RBAC, Provider, болон admin-users бүлгүүдийг дутуу
  агуулж, устгасан password/OTP/registration auth route-уудыг одоо ч жагсаадаг.
- `backend/docs/` нь дугаараар нь тус тусын migration файлуудыг лавладаг; тэдгээр нь
  одоо `1_init_schema`-д нэгтгэгдсэн.
- Зарим doc comment (жишээ нь "GORM"-ыг лавладаг middleware) нь pgx / no-ORM
  дизайнаас өмнөх бөгөөд зөвхөн гаднах хуучирсан зүйл юм.
- PAdES гарын үсгийн дэд системд зориулсан тусгай `SIGNING.md` doc хос хараахан
  байхгүй — энэ нь энд [Баримт бичгийн цахим гарын үсэг](signing/index.md)-д
  баримтжуулагдсан.
